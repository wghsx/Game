# 樱町计划（SakuraBlock）

一款 3D 模拟经营游戏。玩家经营一条日式街区，通过店铺招商、居民满意度和街区等级推进成长。

本文件只收录本项目特有的词汇，不写实现细节、不写规范条文。

## Language

**格（Cell）**，3D 世界的最小空间单位，1×1 米的正方形地块。所有建筑与道具按格对齐。
_Avoid_ 方块、格子、tile

**街区（Block）**，玩家经营的空间单位，由若干格组成、沿一条道路两侧排布的建筑与设施集合。
_Avoid_ 区域、地图、城镇、关卡

**门脸（Facade）**，建筑朝向街道的独立外观层，包含招牌、雨棚与配色，逐店单独设计。
_Avoid_ 外观、皮肤、皮肤包

**占格物体（Footprint Object）**，记录自己占用哪几格的世界物体，建筑是最主要的一类。
_Avoid_ 实体、单位、actor

**街道横断面（Street Section）**，一条街横向切开的固定格序，由后巷、建筑带、人行道、车行道组成。
_Avoid_ 路段、剖面

**后巷（Back Alley）**，建筑背面的 1 格宽通道，用来堆放杂物，不参与玩家动线。
_Avoid_ 后院、夹道

**受控随机（Controlled Randomness）**，街景元素的落位、姿态与配色由带种子的随机过程决定，同时受硬约束与密度倾向调制。同一种子必然复现同一街景。
_Avoid_ 随机生成、程序化生成

**密度倾向（Density Bias）**，把一条街切成若干段、每段带一个元素密度权重，用来制造热闹段与安静段的对比。
_Avoid_ 密度值、权重

**街区种子（Block Seed）**，每个街区独立的随机种子，决定该街区全部受控随机的输出。
_Avoid_ 随机数、seed

**户（Household）**，模拟的基本居住单位，2 到 4 人，带收入、满意度与通勤需求。
_Avoid_ 家庭、居民、人口

**店（Shop）**，模拟的基本经营单位，占地块，带营业额、员工需求与供货需求。
_Avoid_ 商铺、铺子、建筑（建筑是物理载体，店是经营主体）

**模拟真源（Simulation Truth）**，驱动世界的权威数据层，只有户与店两层。屏幕上的 NPC 是它的表现，不是真源。
_Avoid_ 数据层、游戏状态

**日结算（Daily Settlement）**，每游戏日在 04:00 执行一次的批量计算，处理经济、人口、满意度与等级经验。
_Avoid_ 每日更新、结算

**表现层（Presentation Layer）**，从模拟真源按概率抽出来演出的人与物，走完即回收，不存档。
_Avoid_ 渲染层、视觉层

**街区性格（Block Character）**，街区长期的经营取向，共四种，居民街、游客街、手艺街、深夜街。它决定这个街区扩张时用哪把武器。
_Avoid_ 流派、风格、路线

**影响力（Influence）**，一个街区向外辐射的经济与文化吸引力，由店铺吸引力、口碑、环境质量与人流产生，按格衰减且只沿道路传播。
_Avoid_ 人气、声望

**控制度（Control）**，单个格子上各街区影响力的占比，连续取值 0 到 100%。格子的归属看控制度最高的街区。
_Avoid_ 占有率、归属度

**并入（Annexation）**，一个街区的控制度被邻街压到阈值以下并持续若干天后归属易主的事件。并入不是征服，店铺与居民保留。
_Avoid_ 占领、攻占

**性格纯度（Character Purity）**，一个街区内部性格的一致程度，对应 HUD 上的星级。
_Avoid_ 纯度、一致度

**模块组件（Kit Part）**，可跨建筑复用的结构件，如墙体、屋顶、门窗、雨棚、电杆、花坛。
_Avoid_ 模型块、零件、prefab

**像素化等距渲染（Pixelated Isometric Render）**，本项目的画面风格。3D 低模资产经正交相机拍摄、平面着色，再叠加全屏像素化与色阶量化后处理，得到近似手绘等距像素画的观感。
_Avoid_ 像素画、2D 像素风、复古风

**资产规范（Asset Spec）**，所有 3D 资产必须遵守的尺寸、拓扑、UV、命名与导出规则。
_Avoid_ 美术标准、制作规范
