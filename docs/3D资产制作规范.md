# 3D 资产制作规范

版本 v0.1 · 2026-10-15 · 适用项目：樱町计划（SakuraBlock）

本规范面向全部 3D 资产：建筑、模块组件、门脸、道具、角色。与本文冲突的个人习惯以本文为准。

## 0. 一句话

低多边形、顶点色、正交相机、全屏像素化。模型做**准**比做**细**重要。

## 1. 画面基准

| 项 | 值 |
| --- | --- |
| 虚拟分辨率 | 480 × 270 |
| 1080p 放大 | 4× 整数 |
| 1440p 处理 | 5× 居中，左右黑边（不用非整数缩放） |
| 相机 | 正交，无透视 |
| 方位角 / 俯角 | 45° / 30°，固定 |
| 1 格 | 24 × 24 虚拟像素 = 1 米 |
| 视野 | 横向约 20 格，纵向约 11 格 |

规则：

- 关键轮廓（招牌上下沿、门框、雨棚边、路沿）尽量落在 1/24 米网格上，减少像素抖动。
- 不开抗锯齿，边缘统一交给像素化后处理。

## 2. 尺度基准

| 对象 | 尺寸 |
| --- | --- |
| 1 格 / 路面砖 | 1 × 1 米 |
| 建筑一层高 | 3 米 |
| 门洞 | 宽 1.2 米，高 2.2 米 |
| 招牌 | 高 0.8 米，出挑 0.4 米 |
| 雨棚 | 出挑 0.6 米 |
| 角色 | 总高 1.6 米，约 3 头身 |
| 建筑占地 | 2×1 格或 2×2 格 |

## 3. 面数预算

| 资产 | 上限（三角面） |
| --- | --- |
| 小道具 | 200 |
| 模块组件 | 400 |
| 单栋建筑（含门脸） | 2000 |
| 角色 | 1200 |
| 同屏总量 | 300,000 |

- 不做 LOD，用距离剔除 + 遮挡剔除替代。
- 导出前三角化，不留 n-gon。
- 不用高模 + 法线贴图，法线贴图在这个风格下没有意义。

## 4. 材质与颜色

- 建筑、模块组件、道具、角色一律用**顶点色纯色材质**，全场景共用同一个材质。
- 不贴图，不用 PBR。
- 颜色只能取自 48 色调色板（16 色相 × 3 明度）。色板 `T_Palette_48.png` 单独交付。
- 允许用顶点色做假 AO：墙角、屋檐下压深一到两个明度阶。这是最便宜的立体感来源，鼓励用。
- **招牌是唯一例外**：店招文字与 logo 走独立图集 `T_SignAtlas.png`（1024×1024），按 1 像素对齐，不允许跨图集或重叠 UV。
- 透明只用 1-bit 硬边（alpha cutout），禁止半透明渐变贴图。

## 5. 光照与氛围

- 全实时，不做光照烘焙。
- 一盏定向光 + 环境光；阴影贴图 1024，允许它糊。
- 昼夜只改环境光颜色 + 一层后处理调色，按游戏内时间插值。不动态增删光源。
- 夜间店面灯火用自发光材质 + 发光贴片（灯笼、招牌灯箱），不用实时点光源。
- 天气四态：晴、樱花吹雪、雨、夜雨。实现方式是粒子 + 后处理 + 光照参数，不新增模型资源。

## 6. 角色与 NPC

- 所有人类角色共享一套骨架，身高 1.6 米。
- 共享动画库：走、跑、站、聊、打招呼。玩家角色额外有交互动作（E）。
- NPC 播放时随机偏移起始帧，避免动作整齐划一。
- 同屏 NPC 上限 40。
- 角色差异靠配件与配色（发型、制服、包），不靠换模型。

## 7. 建筑与模块组件

结构件模块化，门脸独立。这是控制新增店铺成本的唯一支点。

首版模块组件清单：

| 前缀 | 类别 | 组件 |
| --- | --- | --- |
| KIT_ | 墙体 | Wall_Solid、Wall_Window、Wall_WindowWide、Wall_Corner |
| KIT_ | 屋顶 | Roof_Flat、Roof_Tile、Roof_Awning_Stripe |
| KIT_ | 门窗 | Door_Shop（2.2 米）、Door_Residence、Window_Half |
| KIT_ | 外挂 | Stair_Ext、UtilityPole、RoadMirror、VendingMachine |
| KIT_ | 家具 | Umbrella_Red、Planter、Bench、SignFrame |
| FCD_ | 门脸 | 每店一套：招牌 + 主色 + 2~3 件装饰 |
| PRP_ | 道具 | Lantern、A_Board、Basket、FlowerPot、Postbox、Bin、Bicycle |

规则：

- 门脸朝街，是唯一允许逐店异形的部分。
- 建筑占地只允许 2×1 或 2×2 格，沿街面必须是正面。
- 相邻建筑可以贴靠，但不允许穿插：面与面重合，或留 0.02 米缝隙。

## 8. 街区装配

- 店铺的位置与朝向手工摆。这条街的节奏是设计，不是程序能生成的。
- 道路、路沿、斑马线、人行道、井盖由程序按格自动铺设。
- 同一街区内同时只允许一种路面材质。

## 9. 命名

| 前缀 | 含义 |
| --- | --- |
| BLD_ | 建筑（完整预制体） |
| KIT_ | 模块组件 |
| FCD_ | 门脸 |
| PRP_ | 道具 |
| CHR_ | 角色 |
| ANM_ | 动画剪辑 |
| M_ | 材质 |
| T_ | 贴图 / 图集 |

PascalCase，如 `BLD_ConvenienceStore_A`，末尾 `_A` `_B` 表示变体。禁止中文名、空格，禁止 `final`、`new`、版本号后缀。

## 10. 导出（Blender → Unity）

| 项 | 要求 |
| --- | --- |
| 原点 | 底面中心（脚底贴地） |
| 朝向 | Blender 内正面朝 -Y，Z 轴向上 |
| 缩放 | 已应用全部变换，缩放值 1.0 |
| 负缩放 | 禁止 |
| 顶点色 | 必须导出 |
| 三角化 | 导出前完成 |
| 格式 | FBX 二进制，只导出选中对象 |
| 相机 / 灯光 | 禁止随资产导出 |
| 动画 | 采样率 30 fps |

导出脚本逐项检查上表，任一项不合格直接报错退出，不允许手工绕过。

## 11. 验收

每个资产除了过脚本，还要过三项肉眼检查：

- 在 480×270 下截图：招牌文字能读，建筑轮廓不糊。
- 与相邻资产拼接：缝隙与错位不超过 0.02 米。
- 颜色全部落在 48 色板内。
