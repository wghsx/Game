# 商铺与街区变体设计

版本 v0.1 · 2026-10-15 · 配套《3D资产制作规范》《街区与场景建模规范》

资产清单讲的是「做哪些零件」，本文讲的是「零件怎么组成店，店怎么组成街，街怎么变成很多条」。

## 1. 商铺的五件套

一家店由五部分组成，这也是给建模的分解方式。

| 部件 | 说明 | 是否复用 |
| --- | --- | --- |
| 基座 | 墙体、屋顶、门窗，决定店的体量 | 复用 KIT_ |
| 门脸 | 招牌、雨棚、配色，决定店的识别 | 逐店独立 |
| 招牌字 | 图集贴面，唯一承载文字的部分 | 逐店独立 |
| 橱窗 | 玻璃后面的静态陈列，暗示店内 | 逐店独立 |
| 门口外摆 | 花架、菜单牌、A 字牌、箱子 | 复用 PRP_，每店上限 3 件 |

**每店外摆上限 3 件**，超出会堆成垃圾场。这条和街景演化系统（候选 D）共用同一份预算，以后加生长逻辑时不会打起来。

## 2. 识别点必须在形状和颜色上

这条是从像素密度倒推出来的硬约束，很重要。

1 格 = 24 虚拟像素，招牌高 0.8 米约等于 19 虚拟像素。在 19 像素的高度上，**文字最多放下 4 到 6 个字，再小就糊成一团**。

所以每家店的识别点必须落在**形状和颜色**上，不能指望文字。做法是给每家店规定一个「3 秒识别点」，满足任意一条即可：

- 独特的轮廓，比如居酒屋的瓦檐挑出、便利店的条纹雨棚
- 高饱和的主色块，比如花店的绿、居酒屋的红
- 会发光的东西，比如便利店的灯箱、夜里的灯笼

招牌文字只承担「走近了能读」的精度，不承担「一眼认出」的任务。

## 3. 首版店型

| 店型 | 占地 | 营业时段 | 客流特性 | 识别点 |
| --- | --- | --- | --- | --- |
| 便利店 | 2×1 | 全天 | 稳定基础客流 | 条纹雨棚加灯箱 |
| 居酒屋 | 2×1 | 17:00 到 02:00 | 夜间高峰 | 瓦檐加红灯笼 |
| 茶饮咖啡 | 2×1 | 08:00 到 20:00 | 白天中峰 | 木格栅加遮阳伞 |
| 花店 | 2×1 | 09:00 到 19:00 | 客流低，但抬环境分 | 花架加绿色雨棚 |
| 杂货书店 | 2×2 | 10:00 到 20:00 | 中等 | 大玻璃加挂旗 |
| 正餐餐饮 | 2×2 | 11:00 到 22:00 | 双峰 | 大招牌加菜单牌 |
| 住宅 | 2×1 | 无 | 提供住户 | 阳台加晾衣杆 |
| 地标 | 2×2 | 特殊 | 全局影响 | 独立设计 |

营业时段直接接客流公式里的时段曲线，店型的差异必须体现在营业曲线上，不能只是外观不同。一个白天开门的店和一个通宵的店，如果客流曲线一样，那店型就白分了。

## 4. 街区变体：七个替换维度

同一套 KIT_ 和 PRP_，靠换七个维度生成不同街区。

| 维度 | 首版选项 | 视觉冲击 |
| --- | --- | --- |
| 屋顶样式 | 瓦顶 / 铁皮棚 / 平顶 / 坡顶 | 最强，一眼区分街区 |
| 主色配色 | 暖木 / 冷蓝灰 / 亮白 / 高饱和 | 强 |
| 植被主题 | 樱 / 枫 / 银杏 / 无 | 强 |
| 街道密度倾向 | 稀疏 / 中等 / 密集 / 极密 | 中，靠 ADR-0008 的密度调制实现 |
| 门脸套件 | 和风 / 商用 / 现代 / 复古 / 住家 / 霓虹 | 强 |
| 地面材质 | 沥青 / 石砖 / 土路 | 中 |
| 地标 | 每街区 1 个 | 最强，每街区的记忆点 |

## 5. 变体配方表

不做随机组合，随机组合一定会出现难看的搭配。用配方表手工指定，每个街区一行。

| 街区 | 屋顶 | 配色 | 植被 | 密度 | 门脸 | 地标 |
| --- | --- | --- | --- | --- | --- | --- |
| 樱町（起始） | 瓦顶 | 暖木 | 樱 | 中等 | 和风 | 老樱花树 |
| 港町 | 铁皮棚 | 冷蓝灰 | 无 | 密集 | 商用 | 旧仓库 |
| 学园前 | 平顶 | 亮白 | 银杏 | 规整 | 现代 | 校门 |
| 商町 | 混合 | 高饱和 | 无 | 极密 | 复古 | 拱廊 |
| 住宅町 | 坡顶 | 淡黄 | 枫 | 稀疏 | 住家 | 小神社 |
| 夜町 | 平顶 | 深色 | 无 | 中等 | 霓虹 | 灯箱塔 |

新增一个街区 = 写一行配方 + 做 1 个地标 + 微调配色，约 5 件资产。这是整个项目中复用率最高的一处设计，必须守住。

## 6. 变体的边界

有三件事不能靠换配色解决，必须重做资产：

1. **地标**。地标是街区的记忆点，不能复用。
2. **屋顶轮廓**。屋顶决定天际线，宽高比变了就得重做。
3. **门脸的招牌形状**。文字排版依赖于招牌的宽高，形状一换就要重排。

超出这三样，就不是变体而是新街区了，成本要按新街区算。
