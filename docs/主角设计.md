# 主角设计（草案，待裁决）

版本 v0.1 · 2026-10-15

## 1. 问题

操控主角目前只承担移动与交互。单靠这一层确实站不住，玩家完全可以直接点击界面完成同样的事，走路是多余的。要么给他不可替代的价值，要么砍掉。

## 2. 价值不在操控，在身体在场

操控本身不是玩法，**限制才是**。

主角的全部策略深度来自一句话，我不能同时在两个地方。这个限制逼玩家排优先顺序，排顺序就是玩法。

判定标准很干脆：

- 若主角只是移动加按 E，砍掉。
- 若主角的存在制造了取舍，留下，而且它是最核心的一条。

## 3. 三层价值

### L1 移动与交互

WASD 加 E，参考图里已经有的东西。单靠这层不够。

### L2 身体是稀缺资源

每天只有 3 次亲自出马的机会（见《数值参数总表》第 8 节），亲手做满效果，派店长只能拿到七成。

于是「今天这三件事花在哪」成了每日决策。这是把限制做成玩法，不是把操控做成玩法。

### L3 只有亲自到场才能获得的东西

这一层才是主轴，五条。

| 条目 | 内容 | 为什么不可替代 |
| --- | --- | --- |
| 发现问题 | 没走过的地方，问题不显示。店铺投诉、街角堆积的杂物、破损的招牌，都要靠走才能发现 | 不巡视的街区会静默恶化，玩家会输在自己看不见的地方 |
| 亲自动手 | 亲手处理效果 100%，派店长 70% | 让玩家在「省时间」和「做得漂亮」之间选 |
| 士气 | 每天走过一家店，该店当日客流加 10% | 「今天先走哪条街」成为日常决策 |
| 关系 | 只有亲自接触才能积累与老板、居民的关系值 | 关系值决定他们愿不愿意接受你的提案 |
| 形象 | 玩家角色的装扮与携带物影响游客街的吸引力 | 游客街的性格就是人流磁铁，而玩家是街上最醒目的那个人 |

## 4. 去掉主角的代价

| 损失 | 说明 |
| --- | --- |
| 候选 B 巡视配额 | 首版支柱之一，连根拔掉 |
| L3 全部五条 | 主角相关的差异化归零 |
| 相机 | 从跟随角色改为自由平移，参考图的步行感消失 |
| 资产 | 省下玩家模型 1 件加完整动画集，约 5 人天 |

省下 5 人天的资产，换来砍掉一条支柱。这笔账不划算。

## 5. 折中方案

保留主角，但允许切换视角。上帝视角做规划与建设，角色视角做巡视与交互。

- 好处：同时拿到上帝视角的便利和身体在场的约束。
- 代价：两套相机与两套输入，实现成本中等。

## 6. 建议

主角必须留下，按第 3 节做。

L3 那五条全部依赖「身体在场」这个前提，而它们构成本作与市面街区经营最大的差别。去掉主角，等于把刚刚建立起来的差异化又还回去。

若一定要简化，走第 5 节的折中，不要直接去掉。

## 7. 待裁决
