# 街景用受控随机，不用固定常量

状态：已采纳

最初的想法是把树木、电杆、杂物的间距全部写成常量，铺出来的街景整齐可控。但整齐的代价是廉价，参考图里那种街之所以好看，靠的是疏密起伏和随手摆放的杂物，不是等距阵列。

决定：街景元素用**三层叠加的受控随机**生成。硬约束层是常量且不可打破（建筑朝街、禁区、路沿位置）；低频密度调制把街道切成 8 到 16 格的段、每段带一个 0.3 到 1.4 的密度倾向，制造热闹段与安静段的对比；中频随机把间距从固定值变成区间取值，用泊松盘采样；高频微扰管姿态、缩放、配色和 ±0.15 格的位置偏移。

常量表继续存在，但只放**区间与权重**，不放具体数值。

## Considered Options

- 全部固定常量：街景整齐、易于验证，但一眼假，且玩家很快会看出重复模式。
- 纯随机：够乱，但没有节奏，也没法复现，出了问题查不出来。

## Consequences

- 可控性靠三个抓手落地，全局种子保证可复现，街区种子隔离改动范围，编辑器 pin 允许手动钉住任何一个物体且不被重新生成覆盖。
- 密度倾向值需要调参，这是一项持续的美术调优工作，不是一次写完就结束的。
- 存档必须保存种子与所有 pin 记录，否则读档后街景会变样。这条会影响存档结构，属于早期就要定下的约束。
- 验收标准相应改变，重点从「位置正确」变成「同种子两次生成逐格一致」加「同一条街能看出至少两处疏密差异」。
