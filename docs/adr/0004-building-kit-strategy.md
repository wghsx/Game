# 建筑资产策略：模块化 kit + 门脸独立

状态：已采纳

参考图里四家店形态各异（便利店的条纹雨棚、居酒屋的灯笼瓦檐、咖啡店的木格栅、花店的花架）。这类游戏后续一定会不断新增街区与店铺，如果每家店都从头单独建模，成本会随店铺数量线性爆炸。

决定：**结构件模块化 + 门脸独立**。墙体、屋顶、门窗、雨棚、电杆、花坛等做成可复用的模块组件；而招牌、配色、装饰这层「门脸」逐店单独设计，保证街道上一眼能区分谁是谁。

## Considered Options

- 每栋楼完整单体建模：细节最自由，但完全不可复用。
- 只把屋顶 + 墙面 + 招牌三类模块化：复用度不够，门窗雨棚仍要重复劳动。

## Consequences

- 需要维护一份模块组件的部件清单与尺寸表，它是新增店铺的前提。
- 新增一家店的成本 = 一套门脸，而不是一整栋楼；这直接决定了「街区能开多少家店」这个玩法上限。
