# 渲染风格：低多边形 + 正交相机 + 平面着色 + 全屏像素化

状态：已采纳

参考图是 2D 手绘等距像素画，而本项目要做 3D。如果按常规 3D 做，会立刻丢掉参考图最有价值的东西，像素质感。

决定：采用**正交相机**（固定等距视角）、**低多边形**模型、**平面着色**（纯色 + 顶点色，不使用 PBR 贴图），最后叠加**全屏像素化 + 色阶量化**后处理。这样模型仍是真 3D、可以走标准建模与导出管线，观感则回到手绘等距像素画。

## Considered Options

- 卡通渲染（cel shading）：更像现代日系 3D，干净好看，但丢失「像素」这一核心识别点。
- 体素（MagicaVoxel 方块堆）：制作最快，但方块感很强，与参考图里圆润的招牌、雨棚、花架完全不是一回事。
- 低模 + 手绘像素贴图但不做像素化：清晰度高，同样丢掉了像素质感。

## Consequences

- 后处理参数（虚拟分辨率、色阶数、抖动方式）一次定死，所有资产自动统一，不需要逐资产调风格。
- 模型不使用 PBR 材质，光照细节可以粗糙，像素化会掩盖瑕疵，这是有意为之的省力点。
- 因为是正交相机，场景没有透视纵深，建筑的「进深」需要用遮挡关系而非透视来读，摆放规则要为此让步。
