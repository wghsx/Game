# 资产尺度基准：1 格 = 1 米，角色 1.6 米（约 3 头身）

状态：已采纳

3D 项目最大的返工来源，是每件资产各按手感做，最后拼不到一起、比例错乱。

决定：**1 格 = 1 个 Unity 单位 = 1 米**；**建筑一层高 3 米**，**门洞 2.2 米**；**角色总高 1.6 米、约 3 头身**；**路面砖 1×1 米**。所有资产按这把尺子对齐。

## Considered Options

- 按真实人体比例（角色 1.75 米、7 头身）：与参考图的 Q 版观感不符，且会让街景显得空旷。

## Consequences

- 角色偏矮、门窗比写实尺寸小，这是刻意的风格选择，不是建模误差，后续不要「修正」它。
- 建筑、道具、角色之间可以互换拼装，模块化 kit 才能成立。
