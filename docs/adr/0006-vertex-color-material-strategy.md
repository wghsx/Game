# 材质策略：顶点色纯色材质，招牌单独走图集

状态：已采纳

在「低模 + 正交 + 全屏像素化」的渲染管线下，贴图上的细节会被像素化与色阶量化吃掉大半，逐资产画贴图等于白做。但招牌上的店招文字必须能读，它是画面里唯一需要承载信息的部分。

决定：建筑、模块组件、道具、角色一律使用**顶点色纯色材质**，全场景共用同一个材质，不贴图、不用 PBR；颜色只允许取自 48 色调色板（16 色相 × 3 明度）。**只有招牌/logo 走独立图集** `T_SignAtlas.png`。

## Considered Options

- 共享调色板图集（一张 256×256 手绘贴图共用 UV）：风格上限更高，但需要为每个资产做 UV 展开与图集排布，人力成本远高于收益，且细节仍会被像素化吃掉。
- 每类资产一套贴图：材质数量爆炸，破坏合批，直接撞上移动端预算。

## Consequences

- 全场景材质数量接近 1，合批几乎无损，同屏 40 个 NPC + 整条街区的移动端预算因此变得宽裕。
- 建模时省掉 UV 展开这道工序，只做顶点着色，资产制作速度显著提升。
- 换色/换风格只能通过改顶点色，不能靠换贴图。这限制了后续做「主题皮肤」的做法，若要支持皮肤，需要走顶点色方案而不是贴图方案。
- 假 AO 只能靠顶点色压深实现，不允许用烘焙 AO 贴图。
