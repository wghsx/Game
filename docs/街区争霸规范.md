# 街区争霸规范

版本 v0.1 · 2026-10-15 · 配套《模拟内核规范》《街区与场景建模规范》《玩法候选池》

## 1. 一句话

街区之间互相争夺影响力，非回合制，走日结算通道。争夺的形态是商业兼并，不是战争。

## 2. 三个量

| 概念 | 说明 |
| --- | --- |
| 影响力 | 一个街区向外辐射的经济与文化吸引力，按格衰减并只沿道路传播 |
| 控制度 | 单个格子上各街区影响力的占比，连续取值 0 到 100%。格子的归属看控制度最高的那个街区 |
| 性格纯度 | 一个街区内部性格的一致程度，对应 HUD 上的星级 |

## 3. 影响力怎么算

影响力在日结算通道里算，每天一次。

```
每格影响力 = 街区影响力源强度 × 距离衰减 × 道路连通系数
```

- **距离衰减**按格算。越过建筑与后巷衰减更快，墙是挡人气的。
- **道路连通系数**是关键参数。影响力只能沿道路传播，隔着一排没有路口的建筑，影响力传不过去。这条让「修路」真的成为扩张手段，而不是装饰。

## 4. 控制度与颜色渗透

- 每格控制度每日更新一次，单日变化幅度设上限，暂定 3%，避免一夜变色。
- 画面表现是颜色缓慢渗透，不是跳变。玩家能看到自家颜色往外推。
- 单日变化上限这个参数是整个争霸玩法的节奏旋钮，调它就等于调整局时长。

## 5. 并入

- 触发条件：邻街所有格子的己方控制度超过 70%，且持续 5 个游戏日。
- 并入结果：该街区的店铺与居民归玩家所有，老板可能留下也可能离开（接候选 C）。
- 并入是一次性事件，要有仪式感的表现，不能是数值静默变化。玩家应该记住自己吞下第一条街的那个瞬间。

## 6. 扩张：修路

- 玩家在街区边界修延伸路，新格子控制度从 0 开始。
- 修路要花钱、花时间，而新格子的控制度增长只会来自经营，不会来自继续砸钱。
- 破规矩：**花钱买不到控制度**。这条是底线，见第 11 节。

## 7. 性格决定武器

| 性格 | 主扩张手段 | 效率加成场景 |
| --- | --- | --- |
| 居民街 | 生活品质虹吸 | 住宅密集区 |
| 游客街 | 人流磁铁 | 靠近路口与地标 |
| 手艺街 | 稀缺店铺 | 成片的老铺区域 |
| 深夜街 | 时差错位 | 夜间营业区域 |

不同性格对同一格子的争夺效率不同。性格选定后不能随意更改，转换要付出代价。

## 8. 手段光谱

首版只开良性、灰色两档。

| 档位 | 手段 | 代价 |
| --- | --- | --- |
| 良性 | 开好店、办活动、改善环境 | 见效慢 |
| 灰色 | 挖角邻街名店、价格战、深夜拉客 | 掉自身口碑或满意度 |

恶性档（造谣、断供）留 v1.1。首版先验证核心张力，恶意竞争留到后面。

## 9. 反向压力

- 玩家经营得差，自家格子的控制度会被邻街侵蚀。
- 自家街区控制度跌破 50% 并持续 10 个游戏日，触发被并入的失败结局。
- 这是本作唯一真正的失败条件，比破产更痛，因为它是被对手吃掉。

## 10. 胜负

全城 60% 以上格子归属同一性格即算统一。不做物理占满，避免玩家把地图涂满这种枯燥作业。

## 11. 与内核的边界

这条是底线，写在这里是为了防止后来的人好心办坏事。

**势力扩张只能是经营结果的输出。** 任何「花钱直接买控制度」「独立的军事单位」「战斗数值」这类设计一律不做。经营得好才有扩张力；破了这条，这游戏就变成两个游戏粘在一起，两边都不好玩。

## 12. 验收

- 连续 10 个游戏日完全不经营，自家控制度必须下降。
- 单独修路而不经营，控制度不涨。
- 同一种子与同一操作序列，控制度演化逐日一致。
- 并入事件有明确的表现，玩家能感知到发生了。
