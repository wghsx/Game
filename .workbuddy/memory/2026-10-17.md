# 2026-10-17 · 樱町计划建模重做

## 做了什么

把街区模型从「Three.js 里用 BoxGeometry 现拼」换成「Blender 脚本出 GLB，引擎只加载」。

- 新增 `tools/blender_kit.py`，一条命令重建 36 件资产并导出 GLB，顺带出 3 张 EEVEE 预览图。
- 新增 `public/models/`，36 个 GLB 共 3.5 MB：12 套商铺门脸（各含 2F/3F）、yatai 1F、3 种住宅、4 个地标、1 套街道家具、3 种车辆。
- 新增 `src/assets.js`：并行加载、`clone(true)` 实例化、按 emissive 注册夜间材质、读招牌包围盒贴店名。
- `main.js` 改为异步初始化，`createShopMesh` 统一走 GLB，加载失败回退到旧 `builder.js`。
- 车辆换成 GLB；住宅换 GLB 并给团地补了背面与侧面窗。

## 补齐的功能缺口

- 领地可视化：原来是单轴 19 块瓦片，改成沿两条干道 41 块、按到路口距离排序，控制度涨就往外推。
- 夜间照明：加 8 盏店门前 PointLight；半球光/环境光跟着时段一起降（原来只降主平行光，夜景发灰）。
- 换装：四套衣服各配实体挂件（公文包/头带/柴犬耳尾/围裙工具带）。
- 店铺加层、空地建店改用新管线出模型。

## 踩到的坑

- Blender 5.2 的 Principled BSDF 节点名是本地化的「原理化 BSDF」，必须按 `node.type` 找，不能按名字。
- 世界节点「Background」同样被本地化，按 type 找。
- bmesh 生成的方块没有 UV，贴图贴不上 → 招牌改为单独出一块平面，按包围盒定位。
- 屋顶山墙底边比墙顶高 0.1 m，侧看是浮板 → 压到墙顶并加封檐板。
- 玻璃后没有东西会读成白纸 → 加暗室内壁和货架剪影。
- Vite 默认端口 3000 撞上 VS Code MCP 服务，改到 5173。

### 路面
- 沥青改成可平铺噪声贴图（骨料、补丁、裂纹、油渍）+ roughnessMap + normalMap。
- **根因**：`updateEnvironmentVisuals` 每帧把路面 roughness 写回 0.72、metalness 写回 0.08，把粗糙度贴图乘掉了，所以怎么调都塑料。改成干燥 1.0 / 潮湿 0.34。
- 标线从贴图里拆出来，单独用平面几何铺，合并成 2 个 mesh。

### 性能
- `assets.js` 加了 `flatten()`：加载时按材质合并，一间店从几十个 mesh 压到十来个。
- 场景 mesh 3133 → 940，draw call 303，零报错。

## 修 bug：WASD 走不动

- 现象：网页端按 WASD 人物不动。
- 实际原因：默认视角被我改成了全景，机位锁死 (88,72,88)，角色确实在走（坐标实测 z 从 8 到 -0.59），
  但在那个机位下只是画面里一个点，看着像没反应。
- 处理：默认改成第三人称；全景和自由视角统一冻结主角；在这两个视角下按方向键会弹提示并闪第三人称按钮。
- 出生点从路口正中 (0,8) 挪到人行道 (12,5.8)，开局面朝路口，镜头不再被卡车堵住。
- 踩坑：`const frozen` 声明位置被我插到了使用之后，触发 TDZ 报错 `Cannot access 'frozen' before initialization`，
  整个 update 中断，人物完全不动。这类"先引用后声明"的改动一定要跑一遍真实按键测试。


## 第三人称相机返工

- 反馈：按 WASD 时视角切换太快、不平滑；WASD 仍然动不了。
- 相机甩头的根因：机位角度直接取角色当前的 rotation.y，角色一转向镜头就跟着瞬移，再补插值，看着像被甩。
- 改法：相机自己持有 camYaw / camPitch / camDist 三个量，只由右键拖拽和滚轮改，不跟角色转身；
  位置按球坐标算出来再做指数平滑插值；角色转身改成 faceToward 的角度插值，不再一帧拧过去。
- 移动方向改成相对镜头（W 永远是"往画面里走"），左 A 右 D 不再带着镜头转。
- WASD 可能失效的原因：中文输入法把按键吃掉。给方向键和 E 加了 preventDefault，
  并监听 compositionstart 弹提示；窗口失焦时清空按键表。
- 实测：起点 (12,5.8) 按 W 到 (12,-1.76)、按 A 到 (4.55,-1.76)，camYaw 全程 3.14 不变，
  右键拖拽后 camYaw 3.14 → 1.94，零报错。
